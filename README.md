# E-Commerce Sales & Customer Analytics

## Overview

This project analyzes the Brazilian E-Commerce Public Dataset
by Olist using PostgreSQL.

The goal was to explore sales performance, customer behavior,
product categories, geographic trends, payment behavior, and
delivery performance.

## Tools

- PostgreSQL
- pgAdmin
- SQL
- Microsoft Excel

## Dataset

Brazilian E-Commerce Public Dataset by Olist.

The analysis uses data from:

- Customers
- Orders
- Order Items
- Products
- Payments
- Product Category Translation

## Business Questions

1. How much revenue was generated?
2. How has revenue changed over time?
3. Which product categories generate the most revenue?
4. Which states contribute the most sales?
5. Which customers generate the highest value?
6. How common are repeat customers?
7. Which payment methods are most commonly used?
8. How long do deliveries typically take?
9. What proportion of orders arrive late?
10. How does revenue change month over month?
